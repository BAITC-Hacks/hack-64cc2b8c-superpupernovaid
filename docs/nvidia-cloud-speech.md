# NVIDIA Cloud Speech

Провайдер `nvidia` использует hosted Parakeet 1.1B RNNT Multilingual через Riva gRPC
с TLS. Одна отправка аудио возвращает слова, таймкоды и speaker tags. ASR и diarization
получают результаты одного запроса, без двойной оплаты/повторной отправки.

```dotenv
SPEECH_ENABLED=true
ASR_PROVIDER=nvidia
DIARIZATION_PROVIDER=nvidia
NVIDIA_API_KEY=<секрет в .env>
NVIDIA_ASR_FUNCTION_ID=71203149-d3b7-4460-8231-1be2543a1fca
NVIDIA_LANGUAGE_CODE=ru-RU
NVIDIA_MAX_AUDIO_BYTES=16777216
NVIDIA_REQUEST_TIMEOUT_SECONDS=180
```

Оба провайдера должны быть `nvidia`. Установка локальных моделей, Torch, CUDA и NeMo
не нужна. После изменения зависимостей один раз соберите backend; после изменения
`.env` пересоздайте сервис (одного restart недостаточно для обновления environment):

```sh
docker compose -f compose.yaml -f compose.dev.yaml build backend
docker compose -f compose.yaml -f compose.dev.yaml up -d --no-build --no-deps backend
```

Используется прежний POST `/api/v1/meetings/{meeting_id}/media/{media_id}/speech`.
Аудио отправляется NVIDIA. Ключ не попадает в DTO, fingerprint или сообщения об ошибках.
Ошибки облачного вызова дают 502 без деталей провайдера; автоматических повторов нет.
Успешный результат сохраняется и повторно используется по профилю обработки.

## Границы текущей реализации

- Русский проверен. Казахский отсутствует в списке поддерживаемых языков Parakeet;
  этот режим не закрывает RU/KZ-требование целиком.
- Hosted Whisper Large v3 на тестовом запросе вернул текст, но не word timestamps,
  несмотря на `enable_word_time_offsets`. Поэтому он не выбран для текущего контракта.
- Unary запрос ограничен 16 МиБ **нормализованного WAV** (~8 мин 44 с). Больший файл
  отклоняется с HTTP 413 до чтения в RAM/отправки. Размер исходного MP3 не определяет этот лимит.
  Для длинных совещаний необходим отдельный streaming transport с непрерывными
  speaker IDs; независимое дробление диаризации здесь не применяется.
- Одна активная Speech-задача на процесс, остальные получают 429. gRPC может создавать
  дополнительные копии ограниченного payload; верхняя граница WAV не равна всему RSS.
- Запрашиваются максимум четыре говорящих. Метки анонимны, имен участников модель не знает.
- Нулевые интервалы коротких слов/пунктуации объединяются с соседним текстом. Хвост
  таймкода в пределах 320 мс за концом записи обрезается по фактической длительности;
  большее расхождение считается ошибкой. Времена не генерируются из длины текста.
- Локальные адаптеры сохранены как альтернативы. Канонизация через OpenAI остаётся отдельным этапом.

Официальный API: https://build.nvidia.com/nvidia/parakeet-1_1b-rnnt-multilingual-asr/api
